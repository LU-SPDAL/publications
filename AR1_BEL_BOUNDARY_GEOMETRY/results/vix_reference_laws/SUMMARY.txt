Interpretation guide:
1. If Q is large, variance calibration can be used with the chi-squared law.
2. If Q is small but x is large, the interior finite-Q law addresses the block-count effect.
3. If both x and Q remain finite, the x-dependent finite-Q law retains both effects.
4. If the convex-hull failure probability reaches 5%, no finite nonrandomized 5% cutoff exists.

The fitted-x boundary intervals are numerical sensitivity calculations.
They are not presented as a theorem for an estimated local coordinate.
