# Higher-Order Accuracy of Blockwise Empirical Likelihood

This directory contains the R code and tabulated simulation results supporting
the manuscript “Coverage Error and Bartlett Correction for Nonoverlapping
Blockwise Empirical Likelihood under Weak Dependence.”

## Contents

- [BEL_simulation_code](./BEL_simulation_code/) contains the R scripts used for
  the simulation studies and manuscript figures.
- [BEL_simulation_tables](./BEL_simulation_tables/) contains the canonical CSV
  results and formatted Excel workbooks.

The simulation scripts retain the seeds and numerical settings used for the
reported results. Further details are provided in the README file inside each
subdirectory.
