# Results

The result folders contain compact tables used in the manuscript and in the numerical checks. Large intermediate Monte Carlo objects are not stored here because they can be regenerated from the scripts with the recorded random seeds.

`primary` contains the main coverage, robustness and bandwidth summaries. `unequal_blocks` contains the focused block-ratio experiment. `small_q` contains the small-block-count bridge results. `fixed_q` contains fixed-block-count reference calculations. `application` contains the Brent application summaries. `validation` contains numerical checks of specific calculations.
